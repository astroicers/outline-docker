## Project Overview

Docker deployment of Outline Wiki v1.4 with Keycloak OIDC authentication, Nginx reverse proxy, and Let's Encrypt SSL.

## Architecture

```
Internet → Nginx (80/443)
              ├── wiki.example.com → Outline (3000)
              └── auth.example.com → Keycloak (8080)
                          ↓
                    PostgreSQL + Redis
```

- **Nginx**: Reverse proxy with SSL termination
- **Outline**: Wiki application on internal port 3000
- **Keycloak**: OIDC identity provider on internal port 8080
- **PostgreSQL 15**: Database for both Outline and Keycloak
- **Redis 7**: Session/cache store

## Key Files

- `docker-compose.yml` - Service definitions
- `.env` - Environment variables (DO NOT COMMIT)
- `scripts/setup.sh` - Interactive setup script
- `scripts/doctor.sh` - Read-only health diagnosis (bind mounts / TLS / cert expiry)
- `scripts/initdb/init-keycloak-db.sql` - Keycloak database initialization
- `keycloak/import/outline-realm.json.template` - Keycloak realm template (tracked; placeholder values only)
- `keycloak/import/outline-realm.json` - generated by setup.sh, contains the real OIDC client secret, **gitignored**
- `scripts/deploy-hook.sh` - reloads nginx after certbot renews (mounted into the certbot container)
- `scripts/validate.sh` - validation used by both CI and `make validate`
- `Makefile` - day-to-day entry point for every operation
- `nginx/templates/outline.conf.template` - SSL Nginx config template
- `nginx/templates/outline-temp.conf.template` - HTTP-only config for cert generation

## Setup Flow

1. Run `./scripts/setup.sh` - generates `.env` (chmod 600), the realm JSON, and the nginx configs
2. Start postgres, redis, nginx - the keycloak database is created automatically by
   `scripts/initdb/init-keycloak-db.sql` on first postgres init (do **not** run `createdb` manually;
   it will fail with "already exists")
3. Run certbot for SSL - the command must include `-v $(pwd)/scripts:/opt/scripts:ro` and
   `--deploy-hook /opt/scripts/deploy-hook.sh`, otherwise renewals will never reload nginx
4. Copy SSL config (`outline.conf.ssl` -> `outline.conf`) and start all services

Note: the HTTP-only bootstrap config is `outline-temp.conf.tmpl`. The `.tmpl` extension is
deliberate - nginx loads `conf.d/*.conf`, so naming it `.conf` would leave two server blocks
competing for port 80 (and the temp one wins the glob order).

## Configuration Notes

- OIDC authentication via Keycloak (not Google OAuth)
- First Keycloak user to login becomes Outline admin
- Let's Encrypt certificates expire in 90 days; renewal is automated by the `certbot` compose
  service (12h loop + deploy hook). Do not add a second renewal path such as cron
- nginx adds no security headers: Outline and Keycloak already send HSTS / X-Frame-Options /
  X-Content-Type-Options / Referrer-Policy themselves, and `add_header` would duplicate them
- WebSocket support configured for real-time collaboration
- All bind mounts **of project files** are **directory** mounts, never single-file: single-file bind mounts fail with `exit 127` after a Docker Desktop / WSL2 restart (see README 故障排除). `/var/run/docker.sock` is a deliberate exception — it is provided by Docker Desktop and does not go through the WSL inode cache
- Rate limiting: 1000 requests per 60 seconds
- Max upload size: 256MB

## Development Workflow (SDD)

1. **撰寫規格**: `make new-spec` 建立規格文件到 `docs/specs/`
2. **規格審核**: PR review 或自行確認
3. **實作變更**: 根據規格修改程式碼
4. **執行驗證**: `make validate` (推版前必跑)
5. **提交 PR**: CI 自動執行驗證
6. **合併**: 驗證通過後合併
